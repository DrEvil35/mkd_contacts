# Контактная карта старших по подъездам

Версия v8: обновлённая контактная карта, председатель внизу, скрытие пустого замещающего лица и мягкий цветочный дизайн.

## Что изменено

1. Председатель теперь показывается ниже ответственного по подъезду.
2. Если у замещающего лица нет контактов, его карточка скрывается.
3. Кнопки подъездов упрощены по CSS, чтобы стабильнее выглядеть в разных браузерах.
4. Добавлен мягкий градиентный фон и декоративные цветочные элементы.
5. Соцсети оформлены отдельными цветами:
   - VK — синий;
   - Telegram — голубой;
   - MAX — тёмный;
   - Phone, Email, WhatsApp — отдельные стили.

## Как обновить сайт

Замените файлы в корне репозитория GitHub Pages:

- `index.html`
- `style.css`
- `script.js`
- `contacts.json`
- `README.md`

Файлы должны лежать рядом с `index.html`, не во вложенной папке.
