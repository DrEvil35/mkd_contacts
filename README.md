# Контактная карта старших по подъездам

Версия v6: исправлена устойчивость загрузки и обновлён дизайн.

## Почему мог не отображаться список подъездов

Список подъездов строится JavaScript-ом из файла `contacts.json`.

Если файл:
- не лежит в корне репозитория;
- называется не `contacts.json`;
- содержит ошибку JSON;
- не успел обновиться в GitHub Pages;

то кнопки подъездов могут не появиться.

В этой версии добавлена резервная копия данных прямо в `script.js`.
Даже если `contacts.json` не загрузится, список подъездов всё равно появится.

## Что изменилось в дизайне

- подъезды стали карточками в сетке 2 колонки;
- всплывающее окно стало визуально чище;
- кнопки соцсетей получили разные цвета:
  - VK — синий;
  - Telegram — голубой;
  - MAX — тёмный;
  - телефон, email, WhatsApp — отдельные цвета;
- у каждой соцкнопки есть короткий логотип: VK, TG, MAX и т.д.

## Как обновить сайт

Замените в корне репозитория все файлы из архива:

- `index.html`
- `style.css`
- `script.js`
- `contacts.json`
- `README.md`

Важно: файлы должны лежать рядом с `index.html`, не внутри вложенной папки.
