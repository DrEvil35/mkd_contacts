# Контактная карта совета дома

Версия v10.

## Дом

Шекснинский пр-кт, д.16  
ЖК «Мечта»

## Что изменено

1. В шапке уточнено, что это совет дома Шекснинский пр-кт, д.16, ЖК «Мечта».
2. Для людей с VK-профилем добавлена попытка загрузки аватарки.
3. Если аватарка не загрузилась, остаются инициалы.
4. Председатель остаётся в блоке «Общие контакты».
5. При выборе подъезда показывается только ответственный по подъезду.

## Как работают аватарки

Скрипт ищет VK-ссылку у человека и пробует загрузить картинку по VK-идентификатору.

Если картинка не загрузилась, `onerror` удаляет изображение, и пользователь видит инициалы.

## Как обновить сайт

Замените файлы в корне репозитория GitHub Pages:

- `index.html`
- `style.css`
- `script.js`
- `contacts.json`
- `README.md`

Файлы должны лежать рядом с `index.html`, не во вложенной папке.
