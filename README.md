# Контактная карта ответственных лиц

Версия v17.

## Исправление

В `index.html` убраны статичные значения из:

- `important-title`
- `important-summary`
- `page-title`
- `description`
- `footer`
- `top-line`

Теперь эти элементы полностью заполняются из `contacts.json`.

## Важно

Файл называется `contacts.json`, не `contact.js`.

Поле для подзаголовка блока «Важно»:

```json
"important": {
  "summary": "Актуальная информация по голосованию"
}
```

В `script.js` оно подставляется так:

```js
importantSummary.textContent = important.summary || '';
```

## Как обновить сайт

Замените файлы в корне репозитория GitHub Pages:

- `index.html`
- `style.css`
- `script.js`
- `contacts.json`
- `README.md`

Добавлен декоративный слой `flower-ornament` внутри основной карточки.

- используется тот же символ `✿`, что и в верхней строке;
