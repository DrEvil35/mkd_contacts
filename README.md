# Контактная карта старших по подъездам

Минимальный сайт для GitHub Pages.

## Как опубликовать

1. Создайте новый репозиторий на GitHub, например `mkd-contacts`.
2. Загрузите в него файлы:
   - `index.html`
   - `style.css`
   - `contacts.json`
3. Откройте настройки репозитория: `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Сохраните настройки.
6. Через некоторое время страница будет доступна по адресу вида:
   `https://ВАШ_ЛОГИН.github.io/mkd-contacts/`

## Как менять контакты

Редактируйте файл `contacts.json`.

Пример одной кнопки:

```json
{
  "label": "1 подъезд",
  "url": "https://vk.ru/id88635166"
}
```

Можно менять текст кнопки, ссылку, заголовок, описание и нижний текст.
