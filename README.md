# Контактная карта старших по подъездам

Версия v9.

## Что изменено

1. Убрана фраза: «Сначала ответственный по подъезду, ниже — председатель совета дома».
2. При выборе подъезда показывается только ответственный по этому подъезду.
3. Председатель вынесен в общий список на главной странице в блок «Общие контакты».
4. Замещающее лицо удалено из структуры, так как контактов для него нет.

## Как обновить сайт

Замените файлы в корне репозитория GitHub Pages:

- `index.html`
- `style.css`
- `script.js`
- `contacts.json`
- `README.md`

Файлы должны лежать рядом с `index.html`, не во вложенной папке.
