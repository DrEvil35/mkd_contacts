# Контактная карта ответственных лиц

Версия v11.

## Что изменено

1. Убрана загрузка аватарок VK.
2. В аватарках всегда используются инициалы.
3. Заголовок изменён на «Ответственные лица».
4. Верхняя строка изменена на «Совет дома Шекснинский проспект д.16».
5. Строка «Шекснинский пр-кт, д.16 · ЖК «Мечта»» удалена.
6. Палитра стала более контрастной: тёмно-зелёный, бордовый акцент, тёплый фон.
7. Добавлен раскрываемый блок «Важно».
8. Содержимое блока «Важно» хранится в `contacts.json` в поле `important.html`.

## Как редактировать блок «Важно»

Откройте `contacts.json` и измените объект `important`. В поле `html` можно использовать простое HTML-форматирование: `h3`, `p`, `strong`, `ul`, `ol`, `li`.

## Как обновить сайт

Замените файлы в корне репозитория GitHub Pages:

- `index.html`
- `style.css`
- `script.js`
- `contacts.json`
- `README.md`
